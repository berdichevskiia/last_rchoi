# Пакет: Проект — Пользовательский интерфейс (учебный)

## Содержание
- `index.html` — основной одностраничный сайт с разделами, сценарием и демо-формой.
- `styles.css` — стили проекта.
- `script.js` — простая логика формы и навигации.
- `ui_project.zip` — этот архив (включён в архив для удобства скачивания).

## Как запустить
1. Распакуйте архив.
2. Откройте `index.html` в браузере либо запустите локальный сервер:
   ```
   python -m http.server 8000
   # откройте http://localhost:8000
   ```

## Пользовательские сценарии
Полные сценарии находятся внутри раздела "Сценарии" на странице `index.html`. Они описаны подробно, включая ожидаемое поведение и проверки.

## Примечания по интеграции аналитики
В `index.html` показано, где вставлять код Яндекс.Метрики. Для реального слежения замените примерный идентификатор на реальный и разверните сайт на HTTPS-домене (рекомендуется GitHub Pages).
